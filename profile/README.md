## What Is NiceLabel Designer

NiceLabel Designer is the design application in the NiceLabel / Loftware labeling line. You build a canvas, place barcodes and text, then bind those objects to NiceLabel Designer variable data from a spreadsheet or database you already administer. NiceLabel Designer dynamic labels are what you get when the same template prints a different row without a new file for each item.

Operations teams look for NiceLabel Designer compliance layouts because food, chemical, and medical shipping labels often have required blocks. A designer that only draws static stickers becomes painful when dates and lot codes change every batch. NiceLabel Designer Loftware designer is the seat where those blocks are placed once and then filled from data you own.

NiceLabel Designer is not a general drawing program. It is a local labeling designer for printers you already run and goods you already ship. A food plant, a 3PL desk, or a brand that prints its own cartons on a PC it owns can keep templates in one library and leave other brands' artwork out.

## Starting with NiceLabel Designer

Prerequisites: A PC you own, a printer you already run, and a product table you are allowed to print from.

1. **Prepare:** Open the product list you already keep and confirm the columns for name, lot, and date.
2. **Configure:** Create a canvas in NiceLabel Designer Loftware designer, place barcodes, and bind NiceLabel Designer variable data to those columns.
3. **Test:** Step through a few rows in NiceLabel Designer dynamic labels and print one sample on the printer you run.
4. **Refine:** Adjust NiceLabel Designer compliance layouts so required marks still fit when the longest product name appears.
5. **Apply:** Print the batch for goods you already ship, using only the rows that belong to this run.
6. **Maintain:** Save the template with the line's files, and keep other companies' layouts out of this designer.
